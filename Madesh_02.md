# ⚖️ Python BMI Calculator

A beginner-friendly command-line BMI Calculator built with Python.

---

## 📋 Features
- Takes **weight** (kg) and **height** (meters) as input
- Calculates your **BMI accurately**
- Classifies BMI into categories:
  - 🔵 Underweight
  - 🟢 Normal weight
  - 🟡 Overweight
  - 🔴 Obese
- **Validates user input** to prevent errors

---

## 🛠️ Requirements
- Python 3.x
- No external libraries needed!

---

## ▶️ How to Run

1. Open **Command Prompt**
2. Navigate to your project folder
3. Type:
```
python Madesh_02.py
```

---

## 🧮 BMI Formula

```
BMI = Weight (kg) / Height² (m²)
```

## 📊 BMI Categories
| BMI Range | Category |
|-----------|----------|
| Below 18.5 | 🔵 Underweight |
| 18.5 - 24.9 | 🟢 Normal weight |
| 25.0 - 29.9 | 🟡 Overweight |
| 30.0 and above | 🔴 Obese |

---

## 💡 Example

```
===== BMI Calculator =====
Enter your weight (kg): 70
Enter your height (meters): 1.75

Your BMI: 22.86
Category: Normal weight
```
