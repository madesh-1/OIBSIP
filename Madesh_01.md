# 🎙️ Python Voice Assistant

A beginner-friendly voice assistant built with Python that responds to voice commands.

---

## 📋 Features
- Responds to "Hello"
- Tells current **time** and **date**
- **Searches Google** for any query
- **Opens WhatsApp** Web
- Exits on "bye" or "exit"

---

## 🛠️ Requirements
- Python 3.x
- Internet connection
- Working microphone

---

## 📦 Installation

Install the required libraries:
```
pip install speechrecognition pyttsx3 requests pyaudio
```

---

## ▶️ How to Run

1. Open **Command Prompt**
2. Navigate to your project folder
3. Type:
```
python Madesh_01.py
```

---

## 🗣️ Voice Commands
| Command | Action |
|--------|--------|
| "Hello" | Greets you |
| "Time" | Tells current time |
| "Date" | Tells today's date |
| "Search" | Searches Google |
| "WhatsApp" | Opens WhatsApp Web |
| "Bye / Exit" | Closes the assistant |
