# 🔐 Python Random Password Generator

A beginner-friendly command-line Random Password Generator built with Python.

---

## 📋 Features
- Generates a **random password** based on user preferences
- Allows users to choose:
  - 🔡 Letters
  - 🔢 Numbers
  - 🔣 Symbols
- **Validates user input** to prevent errors
- Supports password length from **4 to 50 characters**

---

## 🛠️ Requirements
- Python 3.x
- No external libraries needed!

---

## ▶️ How to Run

1. Open **Command Prompt**
2. Navigate to your project folder
3. Type:
```
python Madesh_03.py
```

---

## 💡 Example

```
===== Random Password Generator =====
Enter password length (4 to 50): 12
Include letters? (yes/no): yes
Include numbers? (yes/no): yes
Include symbols? (yes/no): no

Generated Password: aB3kR7mNpQ2x
```

---

## 📊 Character Types
| Option | Characters Included |
|--------|-------------------|
| Letters | a-z, A-Z |
| Numbers | 0-9 |
| Symbols | !, @, #, $, %, etc. |
