# 🌤️ Python Basic Weather App

A beginner-friendly command-line Weather App built with Python that fetches real-time weather data.

---

## 📋 Features
- Fetches **real-time weather data** for any city
- Displays:
  - 🌡️ Temperature (°C)
  - 💧 Humidity (%)
  - ⛅ Weather condition
  - 📍 City and Country
- Allows checking **multiple cities** in one session
- **Error handling** for invalid city names

---

## 🛠️ Requirements
- Python 3.x
- Internet connection
- OpenWeatherMap API key (free)

---

## 📦 Installation

Install the required library:
```
pip install requests
```

---

## 🔑 API Key Setup
1. Go to **openweathermap.org**
2. Sign up for a free account
3. Go to **My API Keys**
4. Copy your API key
5. Replace `YOUR_API_KEY_HERE` in the code with your key

---

## ▶️ How to Run

1. Open **Command Prompt**
2. Navigate to your project folder
3. Type:
```
python Madesh_04.py
```

---

## 💡 Example

```
===== Basic Weather App =====

Enter city name (or 'exit' to quit): Mumbai
```
